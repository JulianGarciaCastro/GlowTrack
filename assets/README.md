# Assets

Este directorio contiene los recursos estáticos de la aplicación.

## Imágenes Requeridas

### icon.png
- Tamaño: 1024x1024px
- Formato: PNG con transparencia
- Uso: Icono de la aplicación

### splash.png
- Tamaño: 1242x2436px (relación 9:19.5)
- Formato: PNG
- Uso: Pantalla de inicio

### adaptive-icon.png
- Tamaño: 1024x1024px
- Formato: PNG con transparencia
- Uso: Icono adaptativo para Android

### favicon.png
- Tamaño: 48x48px
- Formato: PNG con transparencia
- Uso: Favicon para web

## Crear Assets

Para crear estos assets, puedes usar:
- Figma
- Adobe Illustrator
- Canva
- Cualquier herramienta de diseño

## Colores del Brand

- Primary: #6366F1 (Indigo)
- Secondary: #8B5CF6 (Purple)
- Accent: #F59E0B (Amber)

## Recomendaciones

1. Usa un fondo blanco o el color primario para el icono
2. Mantén el diseño simple y reconocible
3. Evita texto pequeño en el icono
4. Prueba el icono en diferentes tamaños
